# HTML image vocabulary

| Word | Meaning | Example |
| --- | --- | --- |
| **Element** | A building block of an HTML webpage. | An image element |
| **Tag** | Markup that identifies an element. | `<img>` |
| **Attribute** | Information inside a tag that configures an element. | `alt="Desktop workstation"` |
| **src** | Attribute giving the image location. | `src="images/workstation.jpg"` |
| **alt** | Attribute providing a text alternative. | `alt="Network switch with Ethernet cables"` |
| **Alternative text** | Text communicating the relevant meaning or function of an image. | A description, or the purpose of a linked image |
| **Accessibility** | Designing content so people with different abilities can use it. | Useful image alternatives |
| **File path** | A location used to find a file. | `images/coding.jpg` |
| **Relative path** | A location resolved from the current document. | `images/coding.jpg` from index.html |
| **Width** | Horizontal display dimension. | `width="300"` |
| **Height** | Vertical display dimension. | `height="200"` |
| **Pixel** | A unit used for display dimensions. HTML width and height attributes use numbers without units. | `width="300"` |
| **Aspect ratio** | Relationship between width and height. | 3:2 |
| **Hyperlink** | A clickable connection to another page or location. | `<a href="about.html">About</a>` |
| **Debugging** | Finding and correcting errors. | Repairing an incorrect src path |
