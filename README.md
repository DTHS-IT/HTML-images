# HTML Images Lesson

Build an IT Shop showcase webpage using HTML images. Start with the 28-minute class presentation, then complete the project practice.

## Start in Codespaces

1. Use your teacher's template to create your own repository. Open that repository in GitHub Codespaces.
2. Wait for the included **Live Server** editor extension to install.
3. Open `index.html`. Right-click in the editor and select **Open with Live Server**, or use **Go Live** in the status bar.
4. In the **Ports** tab, open forwarded port **5500** using **Open in Browser**. If needed, add port 5500 in that tab first.
5. Edit HTML, save, and refresh the preview as needed.

The extension previews your static HTML files. You do not need terminal commands or a programming runtime for this lesson. If the extension is missing, install **Live Server** by Ritwick Dey in this Codespace.

For local use, open `index.html` directly in a browser. Keep the images folder beside it. You may also use Live Server in desktop VS Code.

## Project checklist

- [ ] Rewrite the introduction in your own words.
- [ ] Display all three supplied images in the matching sections of index.html.
- [ ] Give each image useful alternative text.
- [ ] Use the HTML attributes `width="300" height="200"` on each image. The supplied images are 1536 by 1024 pixels, so 300 by 200 keeps the same 3:2 proportions.
- [ ] Make the workstation image link to about.html. Use alt text that communicates the link's purpose.
- [ ] Test the image link and the return link.
- [ ] Correct the two path errors in debug.html.
- [ ] Complete debugging-notes.md, including your own temporary path-error test.
- [ ] Save and refresh. Check the page at a narrow browser width too.
- [ ] Commit and push your work to your own repository. Follow your teacher's submission directions.

## Schoology responses

Type code into your teacher's Schoology response fields. Your browser preview shows your webpage; it does not submit answers to Schoology.

## Vocabulary in use

An **attribute** gives information about an HTML **element**. The **src** attribute locates the file. The **alt** attribute supplies its text alternative. A **relative path** starts from the current document's folder.
